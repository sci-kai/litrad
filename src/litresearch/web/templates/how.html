This page shows the exact rules with your current settings (highlighted). Change them in Settings. Each recommendation also has an evidence tree with the numbers for that paper. The same rules are documented in docs/recommendation-criteria.md.

🧭 Overview

  1. Collect candidates from OpenAlex topic searches and Semantic Scholar recommendations for your library.
  2. Filter out what you know, have handled, or what is not a research paper.
  3. Eligibility: keep only papers that are fresh or landmarks.
  4. Score each paper on relevance, impact and timeliness.
  5. Select up to {{ s.n_recommendations }} papers that are strong and diverse, ranked by score.
  6. You decide how deeply to read each one; your marking (abstract → thorough) sets the XP.

One batch per week (Monday–Sunday). You decide which papers go on your reading queue.

1 · 🔭 Where candidates come from

OpenAlex topic searches {{ "✅" if cfg.sources.openalex else "❌ (disabled)" }}

For every query of every topic, two searches in titles and abstracts, sorted by relevance, {{ s.results_per_query }} results each:

  • fresh: articles, reviews and preprints published within the last {{ s.fresh_window_months }} months;
  • landmark: papers above the {{ s.landmark_min_percentile }}th citation percentile, published within the last {{ s.landmark_max_age_years }} years.

Semantic Scholar recommendations {{ "✅" if cfg.sources.semanticscholar else "❌ (disabled)" }}

Semantic Scholar suggests recently published papers similar to a set of positive papers and unlike negative ones:

  • positives: papers you rated ≥ 4 stars or read thoroughly, then your most recent library papers (up to 100);
  • negatives: papers you marked “not relevant” (up to 50). Your feedback steers future batches here.

2 · 🧹 Filters

A candidate is removed if it is

  • already in your Paperpile library;
  • already read (any level) or marked not relevant;
  • on your reading queue;
  • recommended in one of the last {{ s.cooldown_weeks }} weeks (earlier weeks only; it may come back afterwards);
  • containing an excluded term: {% for t in cfg.excluded_terms %}{{ t }}{{ ", " if not loop.last }}{% else %}none set{% endfor %};
  • not a research article, review or preprint (editorials, errata, letters…);
  • a conference abstract from a journal supplement (titles like 0865 …, P-123: …).

3 · ✅ Eligibility: current or important

  • fresh: published within {{ s.fresh_window_months }} months (≈ {{ (s.fresh_window_months * 30.5) | round | int }} days);
  • landmark: older, but cited more than {{ s.landmark_min_percentile }} % of papers of the same field and year (OpenAlex citation percentile), and at most {{ s.landmark_max_age_years }} years old.

Everything else is ignored, so you are never shown papers that are neither current nor important.

4 · 🧮 Score

score = {{ w.relevance }} × relevance + {{ w.impact }} × impact + {{ w.timeliness }} × timeliness

Shares of the score: relevance {{ (w.relevance / wsum * 100) | round | int }} %, impact {{ (w.impact / wsum * 100) | round | int }} %, timeliness {{ (w.timeliness / wsum * 100) | round | int }} %. Each component is between 0 and 1.

🎯 Relevance

relevance = {{ s.similarity_share }} × similarity rank + {{ (1 - s.similarity_share) | round(2) }} × topic bonus

  • Library similarity: SPECTER2 embeddings (scientific-paper vectors from Semantic Scholar) of the candidate are compared with your library; the mean cosine similarity to the {{ s.knn }} most similar library papers is turned into a rank among all candidates (0 = least, 1 = most similar). Papers without an embedding use TF-IDF text similarity of title + abstract instead.
  • Topic bonus: topic weight ÷ highest topic weight for papers found by a topic search; {{ s.s2_only_topic_bonus }} for papers found only by Semantic Scholar's library-based recommendations; 0 otherwise.

🏛️ Impact

  • Landmark papers: citation percentile ÷ 100 (field- and year-normalised, OpenAlex). Without a percentile: citations per year on a log scale, {{ s.citations_per_year_saturation }}/year = 1.0.
  • Fresh papers cannot have citations yet, so the journal counts: log-scaled 2-year mean citedness of the journal (an open impact-factor proxy), where {{ s.top_venue_citedness }} = 1.0; unknown journal = {{ s.unknown_venue_impact }}. Plus up to {{ s.early_citation_bonus }} for early citations (full at {{ s.early_citation_saturation }} citations).

Caveat: journal citedness can be distorted, e.g. by supplements full of meeting abstracts. That is why landmark papers use paper-level percentiles.

⏱️ Timeliness

  • fresh: 0.5 + 0.5 × (1 − age ÷ fresh window): from 1.0 on publication day to 0.5 at the end of the window;
  • landmark: constant {{ s.landmark_timeliness }}.

5 · 🎲 Selection

  • Score floor: only candidates with at least {{ (s.min_relative_score * 100) | int }} % of the best score are considered, so diversity never pulls in weak papers.
  • Diversity (maximal marginal relevance): papers are picked one by one, each time maximising {{ s.mmr_lambda }} × score − {{ (1 - s.mmr_lambda) | round(2) }} × similarity to the most similar paper already picked. With λ = 1 the list is strictly by score; lower λ spreads it across subjects.
  • Up to {{ s.n_recommendations }} papers are picked and shown ranked by score.
