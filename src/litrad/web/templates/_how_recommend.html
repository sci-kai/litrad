2 · 🧹 Filters

Removed if

  • skimmed or deeper, or not relevant (unread library papers stay eligible);
  • on your reading queue;
  • recommended in the last {{ s.cooldown_weeks }} weeks;
  • an excluded term matches: {% for t in cfg.excluded_terms %}{{ t }}{{ ", " if not loop.last }}{% else %}none set{% endfor %};
  • not an article, review or preprint (editorials, errata, letters…);
  • a supplement conference abstract (titles like 0865 …, P-123: …).

3 · ✅ Eligibility: current or important

  • fresh: published within {{ s.fresh_window_months }} months (≈ {{ (s.fresh_window_months * 30.5) | round | int }} days);
  • landmark: cited more than {{ s.landmark_min_percentile }} % of papers of the same field and year (OpenAlex percentile), at most {{ s.landmark_max_age_years }} years old.

4 · 🧮 Score

score = {{ w.relevance }} × relevance + {{ w.impact }} × impact + {{ w.timeliness }} × timeliness

Shares: relevance {{ (w.relevance / wsum * 100) | round | int }} % · impact {{ (w.impact / wsum * 100) | round | int }} % · timeliness {{ (w.timeliness / wsum * 100) | round | int }} % · each component 0–1.

🎯 Relevance

relevance = {{ s.similarity_share }} × similarity rank + {{ (1 - s.similarity_share) | round(2) }} × topic bonus

  • Similarity rank: mean cosine similarity of the SPECTER2 embedding to the {{ s.knn }} closest library papers, as a rank among all candidates (0 = least, 1 = most similar). Without embeddings: TF-IDF of title + abstract.
  • Topic bonus: topic weight ÷ highest weight (found by a topic search) · {{ s.s2_only_topic_bonus }} (found only by Semantic Scholar) · 0 otherwise.

🏛️ Impact

  • landmark: citation percentile ÷ 100 (OpenAlex, field- and year-normalised; a landmark always has one).
  • fresh: journal 2-year mean citedness, log scale, {{ s.top_venue_citedness }} = 1.0 (unknown journal {{ s.unknown_venue_impact }}), plus up to {{ s.early_citation_bonus }} for early citations (full at {{ s.early_citation_saturation }}).

⏱️ Timeliness

  • fresh: 0.5 + 0.5 × (1 − age ÷ fresh window), 1.0 → 0.5;
  • landmark: constant {{ s.landmark_timeliness }}.

5 · 🎲 Selection

  • Score floor: at least {{ (s.min_relative_score * 100) | int }} % of the best score.
  • Diversity (MMR): picked one by one, maximising {{ s.mmr_lambda }} × score − {{ (1 - s.mmr_lambda) | round(2) }} × similarity to the closest earlier pick (λ = 1: strictly by score).
  • Up to {{ s.n_recommendations }} papers, shown ranked by score.
